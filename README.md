A modern AI launcher dashboard built with **PowerShell + WPF**.

AI Hub Ultra provides a centralized graphical interface for quickly accessing popular AI platforms, including text AI, image generation tools, video AI services, voice synthesis platforms, and productivity assistants.

**Ideal for beginners and professionals who regularly work with various AI tools.**

The ZIP file contains an executable file "AI-Hub.exe" - Administrator rights are not required.


Free to use
